# 🎙️ Super Station Studio

Professional Radio Automation & Playout System.

## Project Overview

Super Station Studio is a Windows desktop radio automation and playout application designed for professional radio station operations.

## Core Features

- Music Library
- Playlist Management
- Audio Playout
- Two-Deck Playback
- Crossfade
- Jingles & Station IDs
- Advertisement Scheduling
- Clock Wheel
- Program Scheduling
- 24/7 Automation
- Live Assist / DJ Mode
- Playback History
- Reports
- Multi-Output Audio
- Internet Radio Streaming

## Technology Stack

### Frontend

- Electron

### Backend

- FastAPI

### Database

- Dedicated audio playback engine
